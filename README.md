# Dekat.in

Etalase digital hyperlocal: pembeli menemukan jualan rumahan tetangga dalam radius 3–5 KM, lalu memesan langsung lewat WhatsApp. Tanpa komisi, tanpa ongkir kurir pihak ketiga, tanpa akun penjual.

Proyek mata kuliah Inovasi dan Kewirausahaan Kreatif (IKK), Kelompok Dekat.in.

## Isi repo

| Path | Isi |
|---|---|
| `docs/raw/` | Ekspor tab Google Docs kelompok: Creative Thinking, Customer Discovery, VPC & BMC, MVP |
| `docs/PRD.md` | Product Requirements Document MVP |
| `prototype/` | Prototipe UI interaktif (satu file HTML, buka `prototype/index.html` di browser) |
| `design/Dekatin-Desain-UI-MVP.pdf` | Dokumen review desain UI (10 layar + catatan) |
| `design/screens/` | Screenshot tiap layar (390 px) |

## Fitur MVP

1. Deteksi lokasi dan filter radius 3/5 KM
2. Katalog produk sederhana
3. Tombol 1-klik "Pesan via WhatsApp" dengan template pesan
4. Form unggah produk cepat tanpa akun
5. Label ambil sendiri / diantar penjual

Foto produk di prototipe adalah foto contoh berlisensi terbuka dari Wikimedia Commons; kreditnya ada di `prototype/assets/credits.json`.
